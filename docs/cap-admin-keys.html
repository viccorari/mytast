Meshtastic · Remote administration

Add the Suriname admin keys to a CAP node

App only. Authorizes the Suriname 01 and Suriname 02 controllers to configure this CAP over LoRa. Repeat on every CAP you want to manage remotely.

1The two keys

Suriname 01 · host SCU-b827eb3a09e4 · RAK4631 on USB
doDt9vOuNXfCXzv5qNgspLC3RZzB3sgfJhZAt4zeITQ=
Suriname 02 · host SCU-b827eb399d48 · node on the Pi UART pins
JcTyI8whkglD+o8i3WviOdYGcNbOLJYoGpGaL544S1w=
Highlighted characters are easy to confuse: I = capital i · l = lowercase L · 1 = digit one. The Os in both keys are letters, not zeros.

Each key is 44 characters and ends in =. Copy and paste them — never retype. A single wrong character makes remote admin fail silently, with no error shown.

2Add them in the app

  1. Connect the app by Bluetooth to the CAP — not to a Suriname node. Check that the node name at the top of Settings is the CAP you mean to configure.
  2. Open Settings › Security.
  3. Scroll down past Packet authenticity and Direct Message Key to the Admin Keys card. Its field is Admin Key — "The public key authorized to send admin messages to this node." It is a public key, not a password.
  4. Tap Add and paste the Suriname 01 key.
  5. Tap Add again and paste the Suriname 02 key. A node holds up to 3 admin keys, so one slot stays free.
  6. Leave Managed Device (in the Administration card, further down) OFF.
  7. Tap Save & restart. The CAP reboots and Bluetooth reconnects after about 20 seconds.
Do not enable Managed Device

It locks all local settings: the node can then only be changed by remote admin. If a key is wrong or both controllers are unreachable, the only way back is a physical factory reset.

3Check

  • Reopen Settings › Security: the Admin Keys card lists both keys.
  • Open the Nodes tab on the CAP: both Suriname nodes must appear, and each one's node details must show a Public Key. The CAP needs that stored key to decrypt their admin messages.
  • After the first successful remote admin session, the CAP marks that controller as a favorite automatically. That is expected, and a useful sign that it worked.

4If remote admin fails

CauseFix
Typo in a key Delete it in Admin Keys, paste it again, Save & restart.
The CAP has no public key for the controller On the CAP: Nodes › the Suriname node › request its user info, then retry.
The controller has no public key for the CAP Same check from the controller side: the CAP must appear in its node list with a key.
A controller's key was regenerated Its public key changed. Replace the old key in Admin Keys with the new one.
