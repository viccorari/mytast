Broadcast GPS position every 60 s

Node already on LONG_MODERATE, role CLIENT, region US, primary channel sharing location. Setting names in English, with the Spanish label underneath.

1Open the Position screen

Settings (Ajustes) › Device configuration (Configuración del dispositivo) › Position (Posición)

Not Module configuration — that one holds MQTT, Telemetry and the rest of the modules.

All three are dropdowns or switches — nothing is typed in. Then tap Save: the node reboots and Bluetooth drops for a few seconds. Nothing applies until you save.

3Watch for these while setting it

  1. Broadcast Interval has no free-text field. Pick 1 minute from the list (Unset, 1 minute, 90 seconds, 5 minutes, 15 minutes…).
  2. Smart Position off is confirmed when the Smart Interval and Smart Distance fields disappear. If they are still there, the switch did not turn off.
  3. GPS Polling Interval has no 30 s option — the list is 8 s, 20 s, 40 s, 1 minute, 80 s, 2 minutes… Never go below 10 s: that keeps the GPS powered on permanently.
  4. Reopen Position after the reboot and confirm it still reads 1 minute. That is the value the node actually accepted.

4Verify

  1. Outdoors, wait for the first fix: 1 to 5 minutes cold start. No fix means nothing is sent.
  2. Nodes tab: the last heard counter must reset every ~60 s.
  3. Connect the app to another node and check it there too — that proves the LoRa path, not just Bluetooth.
Two firmware rules that override your 60 s — silently

Channel utilisation gate: with the Client role, position packets are dropped while channel utilisation is ≥ 25 % (Tracker roles get 40 %).
Node-count scaling: above 40 online nodes the interval is stretched automatically — on LONG_MODERATE, 50 nodes ≈ 158 s and 60 nodes ≈ 257 s.
Each packet holds the channel 1.5–2 s on this preset, so one node alone sits near 2–3 % utilisation continuously. Use 60 s only on the node you are actively tracking; 120–300 s otherwise.

To revert: Broadcast Interval back to 15 minutes, Smart Position back ON. Paths, labels and dropdown values verified against the Meshtastic Android app source and firmware.
